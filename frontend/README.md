# Frontend

Questo progetto è stato generato con [Angular CLI](https://github.com/angular/angular-cli) versione 22.1.8.

## Server di sviluppo

Per avviare il server di sviluppo in locale:

```bash
ng serve
```

Una volta avviato, apri il browser su `http://localhost:4200/`. L'applicazione si ricarica automaticamente a ogni modifica dei file sorgente.

## Scaffolding del codice

Angular CLI include strumenti per generare codice. Per creare un nuovo componente:

```bash
ng generate component nome-componente
```

Per l'elenco completo degli schemi disponibili (come `components`, `direttive` o `pipe`):

```bash
ng generate --help
```

## Build

Per compilare il progetto:

```bash
ng build
```

La compilazione produce gli artefatti nella cartella `dist/`. La build di production ottimizza l'applicazione per prestazioni e velocità.

## Esecuzione dei test unitari

Per eseguire i test unitari con il runner [Vitest](https://vitest.dev/):

```bash
ng test
```

## Esecuzione dei test end-to-end

Per i test end-to-end (e2e):

```bash
ng e2e
```

Angular CLI non include di default un framework di test end-to-end. È possibile sceglierne uno in base alle esigenze.
